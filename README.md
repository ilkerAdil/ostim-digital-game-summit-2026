# 2026 Digital Game Summit — OSTİM Technical University 🎮🚀

A clean, responsive event landing page and participant registration interface developed for the **2026 Digital Game Summit** organized by **OSTİM Technical University – Vocational School of Information Technologies (BTMYO)**. 

Developed by **İlker Adil Ünlü** as part of the **BTO125** coursework.

---

## 📅 Event Overview

* **Event:** 2026 Digital Game Summit *(2026 Dijital Oyun Zirvesi)*
* **Organizer:** OSTİM Technical University — BTMYO
* **Date:** December 28, 2026
* **Venue:** Main Campus Conference Hall *(Ana Kampüs Konferans Salonu)*
* **Admission:** Free *(Ücretsiz)*

---

## 🌟 Key Features

* **Institutional Design & Branding:** Styled with OSTİM Technical University's official crimson color palette (`#8b1c24`), institutional logo, and custom gaming-themed circuit background graphics.
* **Session Schedule Table:** Structured timetable detailing session hours, topics (Game Engines, Career & Entrepreneurship, AI Tools for Indie Developers), and hall locations with subtle hover states.
* **Interactive Registration Form:** Includes HTML5 client-side validation (`required`, `type="email"`), custom focus states, and mutually exclusive participant category radio buttons (*Student, Alumni, Industry, Guest*).
* **Confirmation Flow (`kayitBasarili.html`):** Dedicated registration confirmation view featuring a visual checkmark badge and navigation back to the main registration form.
* **Pure HTML & CSS Architecture:** Built using semantic HTML5 elements (`<header>`, `<main>`, `<section>`, `<footer>`) and modern CSS3 layouts (Flexbox, absolute positioning, custom transitions) without external frameworks.
